# AI Workflow Automation Audit

Productized done-for-you service for turning one repetitive business workflow into an automation plan.

## Offer

I audit one workflow and deliver a practical automation report with:

- Current-state workflow map
- Three ranked automation opportunities
- A build-ready implementation brief for the top recommendation
- Guardrails, risks, failure modes, and acceptance checks
- Markdown/PDF-ready report output

The report builder in this repository is an internal delivery tool used to produce consistent client reports. The buyer purchases the audit/spec service, not a self-service template.
