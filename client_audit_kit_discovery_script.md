# Client Discovery Script

Use this script for a 20-30 minute paid or pre-paid workflow audit intake.

## Opening

Thanks for walking through the workflow. I am going to focus on one process, not your whole business. The goal is to identify where time, handoffs, decisions, or errors make automation worth considering.

## Workflow Selection

1. Which process repeats every week?
2. Who starts it?
3. What event triggers it?
4. What tools are involved?
5. What output should exist when the workflow is finished?
6. What breaks most often?
7. Who notices when it breaks?

## Time and Cost

1. How many times does this happen per week?
2. How long does one run take?
3. Who performs the work?
4. What is their approximate hourly cost or opportunity cost?
5. How much rework happens because of missing information?
6. What customer or revenue risk appears when this is delayed?

## Data and Risk

1. What information is required to run the workflow?
2. Which fields are always required?
3. Which fields are often missing or wrong?
4. Is any regulated, private, or sensitive data involved?
5. Which systems should never be changed automatically?
6. What needs human approval?

## Automation Fit

1. Which decisions are rule-based?
2. Which decisions need judgment?
3. What can be drafted automatically but reviewed by a human?
4. What should trigger an alert?
5. What should happen when the automation fails?
6. What would make the first version useful even if it is not perfect?

## Close

I will turn this into a short audit with the current-state workflow, three automation opportunities, a recommended first build, guardrails, and acceptance checks. The next decision is whether to implement the highest-value item or leave it as a documented internal process.
